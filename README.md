# Inkloom Guard - Automated Brand Governance Workspace

An enterprise-grade, real-time safety layer for modern content lifecycles. **Inkloom Guard** acts as an educational and collaborative compliance checker tool that bridges the gap between content creators and brand managers by validating content against tone, claims, privacy, and accessibility benchmarks.

## 🛠️ System Overview & Core Capabilities

Inkloom Guard turns static corporate compliance books into an interactive visual environment running entirely within the user's browser sandbox:

*   **Dynamic Role Switching Interface:** Quick-toggle controls at the header layer allowing instant workspace simulation across **Creator**, **Manager**, and **Authorised Reviewer** perspectives.
*   **Local File Import Subsystem:** Client-side binary parsing system supporting instant local uploads for files like `.txt`, `.md`, `.html`, `.csv`, `.png`, `.jpg`, and `.webp` directly in the session memory.
*   **Rule-Based Scanning Engine:** Parses drafts locally against active rule criteria categories including *Tone*, *Claims*, *Privacy*, *Accessibility*, and *Visuals*.
*   **Dynamic Highlight Layer:** Custom inline DOM mapping that wraps target compliance alerts in high-visibility amber text indicators.
*   **Contextual Analysis Sidebar:** Dedicated analytical panel mapping active warnings directly to explainable descriptions and actionable, one-click text rewrites.
*   **Integrated Audit Dashboard:** Frontend tracking bar running live count indicators, state management tools, and manager approval triggers.

---

## 💻 Tech Stack & Client-Side Sandbox Architecture

To eliminate enterprise data leak vectors and maximize processing speeds, this system utilizes a **100% client-side architecture** with zero database latency:

*   **Structure & Layout:** Semantic HTML5 (`<main>`, `<aside>`, `<header>`) for organized layout encapsulation and optimized system tracking.
*   **Design & Presentation Layers:** CSS3 Flexbox components paired with a customized high-contrast professional color standard (Slate gray workspace base, Emerald green success alerts, and soft Amber warnings).
*   **Interactivity Core Logical Engine:** Pure Vanilla JavaScript (ES6+). Executes client-side string parses, structural array filters, dynamic DOM mutations, and localized local storage persistent session flows without framework loading blockages.
