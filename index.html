    START HERE

    How the workspace works

    Inkloom is a GreenSteps brand-content workflow. A creator prepares a draft and runs the guideline review. When it is ready, the creator requests approval. A manager checks the submission, either requests changes or approves it, and can publish approved content.

    1. Create: choose a content type, write or import the draft, and review it.
    2. Resolve: consider findings, make edits, and review the changed draft again.
    3. Approve: submit the draft for a manager decision.
    4. Publish: the manager approves and publishes it from the approval inbox.

    Important: the guideline checker is a rule-based demo. It is not legal advice, factual verification, or a substitute for human review.

    NAVIGATION

    Roles and navigation

    • Creator: edits and reviews drafts, requests approval, and uses Insights to view feedback and review history.
    • Manager: works from the Approval inbox to search submissions, request changes, approve, publish, and view prior decisions.
    • Authorised reviewer: can review drafts, approve them, and publish approved content in the shared workspace.

    Use the role selector in the header to switch views. Workspace opens the creator workspace or manager inbox according to the selected role. Insights is available to creators and reviewers. Manual stays available in every role.

    CREATOR WORKFLOW

    Create and submit content

    1. In Workspace, choose the content type: website/landing page, social post, marketing email, product description, or visual asset caption.
    2. Write in the Draft content editor. To import, choose Import draft; supported files include TXT, MD, HTML, HTM, CSV, PNG, JPG, JPEG, and WEBP. Imported files are read locally in this prototype.
    3. Select Review content. Read each finding and its explanation and recommendation. Use Apply suggestion only when the edit is appropriate, or Mark reviewed when a person must verify it.
    4. Edit the draft where needed, then select Check again. Any edit after a review invalidates the old review; run checks again before requesting approval.
    5. When no high-risk blockers remain, select Request approval. The submission appears in the Manager approval inbox.

    Draft changes autosave in the current browser. The save indicator shows when the draft is saving, saved, restored, or could not be saved.

    GUIDELINE CHECK

    Understand review findings

    Findings are grouped by topic, with a severity, explanation, and (where available) a suggested edit. High-risk and critical findings block approval until resolved. Advisory findings can still be reviewed by the team.

    • Apply suggestion: replaces the matched wording with the suggested wording. Read the draft afterward to ensure the meaning is still correct.
    • Mark reviewed: records that a human verification is needed; it does not independently prove a claim is accurate.
    • Custom-copy changes: edits to copy that departs from the starting or approved text may be flagged for review. Treat the finding as a prompt to verify, not an automatic rejection.

    When a finding is stale because the draft changed, run the review again to refresh findings. The editor’s word count and the live workflow status update as you work.

    MANAGER WORKFLOW

    Review approvals and publish

    1. Open the Approval inbox. Search by title or content, and use the filter to show pending approvals, revised pending submissions, or items with changes requested.
    2. Open and read the submitted content. For revised content, expand the comparison to inspect the previous and current versions. Review guideline findings and version history as needed.
    3. Select Approve content to approve the submission, or enter a clear explanation in the feedback field and select Request changes. A reason is required so the creator knows what to address.
    4. After approval, select Publish to publish the approved version. The latest published content becomes the starting point for the creator’s next draft.

    Published and approved items are listed under Previously approved. The creator can see manager feedback in Insights and choose Review again to reopen rejected content for revision and resubmission.

    HISTORY AND FEEDBACK

    Insights and history

    Insights brings together team guidance patterns, manager-requested changes, and previously reviewed content. Expand a review to read its saved draft, findings, and any available version timeline. The manager’s decision history is available in the Manager inbox.

    Use New review to return to the workspace and start another review. Review history and approval records are stored in this browser and may not be shared with other devices.

    STATUS REFERENCE

    Workflow statuses

    Draft
    Content is editable and has not been submitted for approval.
    Awaiting approval
    A creator submitted the current reviewed version to the manager.
    Changes requested
    The manager returned feedback. Reopen the item from Insights, revise it, review again, and resubmit.
    Approved
    A manager or authorised reviewer approved the submission; the manager can publish it.
    Published
    The approved version is published and becomes the latest starting copy for a new creator draft.
    LOCAL DEMO

    Drafts, privacy, and prototype limits

    This is a browser-based prototype. Drafts, review history, approval decisions, and inbox filters are stored in this browser’s local storage. The page does not upload drafts to a server, sync them to other devices, or provide real user accounts or access control.

    Use sample or non-sensitive content only. Browser storage can be cleared by browser settings, private browsing, or device changes. The app’s “Private workspace” label describes the local demo behavior; it is not a security or confidentiality guarantee.

    INCLUSIVE USE

    Keyboard and accessibility

    • Use Tab and Shift+Tab to move through controls; use Enter or Space to activate links and buttons.
    • Use the “Skip to main content” link at the start of keyboard navigation to bypass the header.
    • Expandable version comparisons and saved content use standard disclosure controls; activate their summary to open or close them.
    • The interface provides visible focus, status announcements, and reduced-motion support. Your operating system’s forced-colors settings are supported.
    HELP

    Troubleshooting

    My approval button is disabled. Why?
    Resolve all high-risk and critical findings, then run the review again. The action becomes available when no blockers remain.
    Why did my review findings disappear?
    Editing a draft invalidates its previous review. Select Check again to review the latest version.
    Where can I find a rejected submission?
    Creators can find manager feedback under Insights → Changes requested, then select Review again.
    Why can’t I see content I saved on another device?
    This prototype stores data only in the current browser and does not synchronize between devices.
    Can the guideline review verify factual or legal claims?
    No. Findings are demo rule matches. A qualified person must verify facts, claims, rights, and final publication readiness.
